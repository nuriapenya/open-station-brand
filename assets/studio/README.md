Dashicons font and stylesheet from WordPress Core (wordpress-develop/src/wp-includes).
Original project: https://github.com/WordPress/dashicons
Licensed under GPL v2 or later; see LICENSE.txt. Used to preview the public Dashicons names accepted by theme manifests.

`components.js` is generated during dev/build from the checked-in GPL UI snapshot in `vendor/alcazaba-ui/`; it is not committed. The studio needs no live plugin checkout or WordPress runtime. See the snapshot README for provenance and licensing.

`dock/` contains copied shell icon artwork with source hashes. `textures/` contains the six generated example materials and their generation notes.
